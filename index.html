Why Antigravity? More than a chatbot

agent جوه بيئة تطوير: يخطط وينفذ ويختبر

MCP

Connects the agent to external tools and data. Docs examples: database schemas, deployment logs, Linear, Notion, GitHub.

Rules

Fixed constraints. Example: use semantic HTML, never put secrets in frontend code.

Skills

Reusable procedures. Example: a UI review checklist in a SKILL.md file.

Subagents

Split work such as research, builds or test runs. Each starts with a clean context.

Beginner setup: Antigravity App • Git for a baseline commit • personal Google account (18+)

Connect a tool in 5 steps

وازاي نوصّل أداة خارجية؟ (MCP في الـ App)

1 Open Customizations in the sidebar, then MCP Servers
2 Click Add MCP Server (+)
3 Pick a server and click Add
4 Describe the task to the agent
5 Review permissions and approve important actions

Example prompt

Check the latest deployment logs, explain why the build failed, propose a fix, and wait for my approval.

Careful

An MCP server can run actions, not only read data. Check its source and permissions. No automatic Google Sheets link: we must define and authorize it.

Steps 1–3: Download, Sign in, Project

الأساس قبل أول prompt

1

Download

Official page, Antigravity App. Windows x64 or ARM64. Windows 10 64-bit or later; macOS and Linux listed too.

2

Sign in

Sign in opens Google authentication in the browser. 18+; Egypt is listed. School or work accounts are managed and may differ.

3

Create a project

New Project, Add Folder, Create. Local mode or New worktree. A worktree is not a backup or a sandbox.

Steps 4–5: Requirements and Plan

اكتب المطلوب، وراجع الخطة قبل أي تعديل

Step 4: Requirements

Build: CS Student Portfolio. Constrain: HTML, CSS, JS. Verify: Skills tabs work, Copy Email shows feedback, responsive at 390px.

Step 5: /plan, then review

Check scope, files and test plan. Leave comments, then approve.

Video 1: Planning & Building inside Antigravity Open Live Portfolio ↗

Step 6: Build with the Right Context

الـ prompt الجيد يحدد الهدف والحدود

Give context

Mention files or folders with @. State the expected behavior and the done condition.

Watch what runs

The agent edits files and runs terminal commands within its permissions. Understand what you approve.

Steer, don't restart

Point to one failing behavior and ask for a focused fix. Then re-run the same test.

Example feedback: "The Copy Email button doesn't show a confirmation message after clicking."

Step 7: Test in the Browser

الشكل وحده مش دليل إن التطبيق صحيح

1. Open
2. Interact
3. Inspect
4. Fix
5. Re-test

Ask for real interaction

Click Skills tabs, copy email, scroll projects, and resize to mobile.

Inspect more than pixels

Console errors, failed network requests, mobile-width layout (390px).

Know your setup

Built-in browser: personal accounts, newer App versions. Other surfaces may need Chrome.

Step 8: Review Changes and Evidence

راجع الـ diff قبل ما تعتمد النتيجة

Review → student-portfolio (+3 files)

+ index.html (Hero profile, Skills tabs, Projects, Contact)
+ style.css (Responsive 390px layout, Cyber Cyan/Navy)
+ app.js (Category filter + Copy Email toast feedback)

Walkthrough Validation
✓ Filter Skills (All / Web / CS Core)
✓ Copy Email feedback works
✓ Mobile 390px & 0 console errors

File-by-File Diff

Compare Uncommitted, Branch and Agent Edits. Comment on a line. A test that ran is not the same as a test that was recommended.

Careful

Discard unstaged changes can delete untracked files immediately.

Steps 9–10: Customize, Set Limits, Check Cost

القوة محتاجة حدود، والمجاني مش unlimited

9. Customize

Rules set constraints. Skills hold repeatable procedures. MCP connects tools. Start with a demo folder and the least access needed.

9. Protect data

No passwords, client secrets or production data. Personal-account terms: interactions may be used to improve products. Enable Telemetry is under Account settings.

10. Cost and quotas

$0 Individual plan with a weekly baseline quota. Pro and Ultra: higher quotas. Pricing lists legacy models removed on 30 Nov 2026.
